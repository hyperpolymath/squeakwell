=== What's Missing

==== Engine (CRITICAL — blocks everything else)

* [ ] Fixpoint loop over partial octads (guarded fill, resolve, measure);
  `max_iterations` is parsed but never used
* [ ] Lexicographic measure `(|missing|, nconflicts)` and a test that it
  strictly decreases or the state is a fixpoint (the Progress invariant in
  `src/abi/mod.rs`)
* [ ] Proptest laws for `resolve`: commutative, associative, idempotent,
  permutation-invariant (the join-semilattice conditions that make
  verisimdb `Octad.v` merge theorems apply)
* [ ] Golden damaged-dataset fixtures (CSV + JSON fragments with deleted
  and contradicted fields) with expected review-queue contents

* [ ] Integration test against a running `verisim-api` (podman), gated

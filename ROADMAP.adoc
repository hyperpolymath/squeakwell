= squeakwell Roadmap
:toc:
:icons: font

squeakwell is a database recovery tool: fragments are scattered across
VeriSimDB's eight modalities, which then act as witnesses that reconstruct
and cross-check each other until the entity converges. VeriSimDB is the
required underlying database. The detailed route (architecture options,
proof ladder, session plan, decisions) is `docs/ROUTE-PLAN.adoc`.

== Phase 0: Scaffold (COMPLETE)
* [x] RSR template with full CI/CD
* [x] CLI with subcommands (`ingest`, `recover`, `status`, `confidence`,
  `review`, `export`, `explain`)
* [x] Stub engine, stub ingest, VeriSimDB client skeleton
* [x] 23 tests against the stubs
